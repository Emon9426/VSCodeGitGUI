本次两项修改：
① 中文路径修复 —— git 默认把非 ASCII 路径转成八进制转义（\357\274\210 = 全角左括号 （）。现已在 git 参数加 core.quotepath=false + 解析端兜底解码，中文路径正常显示。见 场景 B 的「修复前 / 修复后」对比。
② 作者 → 目录 → 文件 三层分组 —— 作者头（粗体，按最新提交在前）汇总其提交/文件数；目录头只显示一次路径（根目录为仓库绝对路径）；文件行 = 文件名 + 大小 + 修改时间，行尾常驻两个按钮：📄 打开文件（编辑器打开）、📁 在资源管理器中定位（选中该文件，长路径自动降级祖先目录）。同作者同文件多次提交合并为一行标 ×N；已不在工作区的文件大小/时间显示 —（悬停有提示）。按钮点击在本页中弹模拟提示（真实扩展走宿主执行）。
